# Ira Workspace v4.0

Telegram Mini App и рабочее пространство преподавателя английского языка.

## Что уже работает

- главный экран с уроками, задачами и подсказками Иви;
- ученики и подробные карточки;
- календарь с динамическими датами;
- подготовка и заметки по уроку;
- заявки и воронка;
- контент-доска для Threads, Telegram и Instagram;
- касания: игры, продукты, материалы, Taplink и соцсети;
- аналитика;
- светлая и тёмная темы;
- экспорт и импорт резервной копии;
- адаптация под Telegram Mini App: тема Telegram, имя пользователя, Back Button, haptic feedback, safe area;
- автоматическая публикация в GitHub Pages после каждого изменения в ветке `main`.

## Локальный запуск

```bash
npm install
npm run dev
```

## Сборка

```bash
npm run build
```

## Публикация

Репозиторий рассчитан на адрес:

`https://bolachkova004-droid.github.io/ira-workspace/`

1. Загрузите содержимое проекта в корень репозитория `ira-workspace`.
2. В GitHub откройте `Settings → Pages` и выберите `Source: GitHub Actions`.
3. Дождитесь зелёного статуса workflow во вкладке `Actions`.
4. Откройте опубликованный адрес и проверьте приложение.
5. Подключите этот адрес к боту `@ira_workspace_bot` через BotFather.

Подробные шаги находятся в файле `TELEGRAM_SETUP.md`.

## Хранение данных

Текущая версия хранит данные локально в браузере. Для резервной копии используйте `Настройки → Экспорт`.
