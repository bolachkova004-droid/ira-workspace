# Подключение Ira Workspace к Telegram

## 1. Опубликовать приложение

После загрузки файлов в GitHub откройте репозиторий:

`bolachkova004-droid/ira-workspace`

Затем:

1. Откройте `Settings`.
2. В левом меню выберите `Pages`.
3. В разделе `Build and deployment` выберите `Source → GitHub Actions`.
4. Перейдите во вкладку `Actions`.
5. Дождитесь, когда запуск `Deploy Ira Workspace to GitHub Pages` станет зелёным.

Рабочий адрес:

`https://bolachkova004-droid.github.io/ira-workspace/`

## 2. Подключить Mini App к боту

Откройте в Telegram `@BotFather` и выполните:

1. `/mybots`
2. Выберите `@ira_workspace_bot`.
3. Откройте `Bot Settings`.
4. Выберите `Configure Mini App`.
5. Нажмите `Enable Mini App`.
6. Вставьте адрес:
   `https://bolachkova004-droid.github.io/ira-workspace/`
7. Загрузите иконку приложения из файла `public/icon.svg`, если BotFather попросит изображение.
8. Укажите название `Ira Workspace`.

После этого приложение появится в профиле бота и будет открываться внутри Telegram.

## 3. Быстрая проверка

Проверьте внутри Telegram:

- приложение открывается на весь экран;
- имя в приветствии берётся из Telegram;
- тёмная тема корректно переключается;
- кнопка Telegram «Назад» работает в карточке ученика и в уроке;
- данные сохраняются после закрытия и повторного открытия на том же устройстве;
- экспорт резервной копии работает.

## Важное ограничение текущей версии

Данные хранятся локально на устройстве. Они не синхронизируются между телефоном и компьютером. Перед сменой устройства скачайте резервную копию в разделе «Настройки».
