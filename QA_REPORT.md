# QA Report — Ira Workspace v6.0

## Проверено

- TypeScript/TSX успешно транспилирован в статическую папку `docs/src`.
- Все 25 JavaScript-файлов прошли `node --check`.
- Все относительные JavaScript-импорты в `docs/src` существуют.
- `docs/health.json` сообщает версию 6.0.0.
- GitHub Pages-версия не требует npm-сборки: используется `/docs` и import map.
- Сохранена миграция данных из ключей localStorage v5 в v6.
- Сообщения с режимом `На проверку` пропускаются серверным обработчиком до одобрения.
- Supabase-миграция v6 добавляет режим доставки и таблицу правил уведомлений.

## Ограничение проверки

Полный `npm install` в текущей среде не выполнен: внутренний npm registry не содержит нужную версию `@types/react`. Поэтому Vite production build здесь не запускался. Статическая версия `/docs`, которую использует GitHub Pages, была скомпилирована отдельно и проверена синтаксически.

## Требует внешних данных

Нельзя проверить без личных секретов пользователя:

- реальную отправку через Telegram Bot API;
- Supabase проект и Cron;
- webhook бота;
- привязку реального Telegram ID ученика.
