# Ira Workspace 7.5.0

- Кнопка сохранения ученика больше не зависит от отправки формы: используется прямой обработчик, окно закрывается сразу, облако синхронизируется в фоне.
- В карточке ученика можно выбрать «Абонемент» или «Разовые занятия».
- В каждом уроке можно отметить, списывается ли он из абонемента или является разовым.
- Для разовых занятий считается количество неоплаченных проведённых уроков и долг.
