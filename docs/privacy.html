Политика конфиденциальности

Rasmus — закрытое рабочее пространство преподавателя. Локальная копия кабинета хранится на устройстве преподавателя, а синхронизируемая копия — в проекте Supabase владельца Rasmus.

Какие данные обрабатываются

Telegram user ID преподавателя; имя и username, если они доступны; введённые преподавателем сведения об учениках, расписании, домашних заданиях, материалах, пакетах занятий, оплате и рабочих заметках; техническая версия приложения и платформа. Для ученика Telegram user ID, chat ID и username сохраняются только после самостоятельного запуска бота по персональной ссылке.

Изоляция кабинетов

Telegram Mini App initData проверяется на сервере и обменивается на сессию Supabase Auth. Запросы преподавателя ограничиваются membership-политиками Row Level Security его workspace. Административная сводка beta не включает список учеников, уроки, оплату или заметки участника.

Приглашения и ученический портал

Приглашения одноразовые или ограничены сроком. В базе хранится хэш токена, а не исходная ссылка. Ученический портал возвращает только имя, ближайшие уроки, домашние задания и расчётные данные оплаты самого ученика; личные заметки и учебная диагностика преподавателя не выдаются.

Уведомления и отзывы

Rasmus использует Telegram для согласованных напоминаний. Отзыв из beta содержит текст сообщения, текущий экран, версию и платформу; содержимое кабинета и данные учеников к отзыву автоматически не прикладываются.

Google Calendar

Подключение добровольное и выполняется через Google OAuth. Rasmus запрашивает доступ к событиям календаря и адресу аккаунта для отображения подключения. Refresh token хранится в зашифрованном виде; пароль Google приложение не получает. Подключение можно отозвать в настройках Rasmus или Google Account.

Сброс и удаление

Преподаватель может удалить записи вручную. При безопасном сбросе тестового кабинета создаётся снимок на 7 дней, после чего он подлежит удалению. Для исправления или удаления сведений ученик обращается к своему преподавателю; участник beta — к владельцу Rasmus.

Сторонние сервисы

Для работы используются Telegram и Supabase; Google Calendar — только после отдельного подключения пользователем.
