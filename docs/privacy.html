Политика конфиденциальности Ira Workspace

Ira Workspace помогает преподавателю вести расписание, данные учеников, оплаты, домашние задания и уведомления.

Какие данные обрабатываются

Приложение может хранить имя ученика, контакт в Telegram, сведения о занятиях, оплатах, домашнем задании и учебных материалах. Telegram Mini App также получает базовые данные пользователя, которые Telegram передаёт через защищённый параметр initData.

Где хранятся данные

Без подключения облака данные сохраняются локально в браузере устройства. После подключения Supabase данные могут синхронизироваться с базой владельца приложения. Доступ преподавателя проверяется сервером через Telegram initData. Студент получает доступ только к собственному расписанию и материалам по персональной ссылке.

Уведомления

После добровольной привязки Telegram ID бот может отправлять сообщения об уроках, переносах, оплатах и домашних заданиях. Пользователь может прекратить взаимодействие с ботом или обратиться к преподавателю для удаления связи.

Передача третьим лицам

Данные не продаются. Техническая обработка может выполняться сервисами Telegram, GitHub Pages и Supabase в пределах функций, необходимых для работы приложения.

Удаление

Локальные данные удаляются через раздел «Настройки». Для удаления облачных данных ученик обращается к преподавателю, управляющему рабочим пространством.

Дата обновления: 1 августа 2026 года.
