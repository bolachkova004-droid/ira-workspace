Политика конфиденциальности Ira Workspace

Ira Workspace хранит внесённые пользователем данные локально в браузере устройства. В текущей версии приложение не передаёт данные учеников, уроков, заявок и контента на внешний сервер.

При запуске внутри Telegram интерфейс может получить базовые данные профиля, которые Telegram передаёт Mini App. Они используются только для персонализации приветствия и не отправляются разработчиком третьим лицам.

Пользователь может удалить локальные данные в разделе «Настройки» с помощью функции сброса.

Дата обновления: 1 августа 2026 года.
