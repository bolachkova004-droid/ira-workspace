Политика конфиденциальности

Ira Workspace хранит демонстрационные данные локально в браузере пользователя. Публичная версия не передаёт данные третьим лицам и не отправляет сообщения в Telegram без отдельно подключённого защищённого серверного компонента.

Telegram

Приложение может использовать интерфейс Telegram Mini Apps для оформления окна. Токен бота не хранится в публичном коде.
