Политика конфиденциальности

Rasmus — рабочее пространство преподавателя английского языка. Приложение хранит локальную копию данных на устройстве преподавателя. После добровольного подключения облачной синхронизации данные также сохраняются в отдельном проекте Supabase, которым управляет владелец приложения.

Какие данные могут обрабатываться

Имя ученика, Telegram username и chat ID, уровень английского, цели обучения, расписание, домашние задания, материалы, информация о пакете занятий и оплате, а также рабочие заметки преподавателя.

Для чего используются данные

Для ведения расписания, предоставления ученику личного кабинета и отправки согласованных уведомлений об уроках, переносах, отменах, домашнем задании и оплате.

Telegram

Идентификатор Telegram сохраняется только после того, как ученик сам запускает бота по персональной ссылке. Токен бота хранится в серверных секретах Supabase и не публикуется в GitHub или клиентском коде. Данные Telegram Mini App проверяются на сервере перед доступом к кабинету преподавателя.

Доступ ученика

Ученик получает доступ только к собственной информации по персональной защищённой ссылке. Он не получает доступ к CRM преподавателя или данным других учеников.

Удаление данных

Для исправления или удаления данных ученик может обратиться к преподавателю. Владелец приложения может удалить запись ученика, его Telegram-привязку и связанные данные из Rasmus.

Сторонние сервисы

При включённой облачной версии используются Telegram и Supabase в объёме, необходимом для работы приложения и уведомлений.
