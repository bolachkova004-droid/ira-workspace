# Начать здесь

Версия 5.0 уже содержит новый дизайн, календарь, личный кабинет ученика и серверную часть уведомлений.

## Сначала обновить приложение

1. Загрузите содержимое этой папки в корень репозитория `ira-workspace`.
2. Подтвердите замену файлов.
3. GitHub Pages должен по-прежнему публиковать ветку `main`, папку `/docs`.
4. Проверьте:
   `https://bolachkova004-droid.github.io/ira-workspace/health.json`
5. В ответе должна быть версия `5.0.0`.

## Что будет работать сразу

- новый paper-planner дизайн;
- месячный, недельный и дневной календарь;
- переносы и отмены уроков;
- очередь оповещений;
- демонстрационный student portal;
- персональные ссылки учеников;
- локальные данные и резервная копия.

## Что требует однократного подключения

Чтобы ученики видели именно ваши реальные изменения с другого устройства и сообщения действительно отправлялись в Telegram, нужно подключить Supabase:

1. выполнить `SUPABASE_SETUP.md`;
2. выполнить `TELEGRAM_BOT_SETUP.md`;
3. вставить адрес Supabase в `docs/config.js` и `public/config.js`.

Секретные токены нельзя заранее положить в архив: Bot Token, Service Role Key и ваш Telegram ID должны храниться только в вашем Supabase-проекте.
