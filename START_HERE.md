# Ira Workspace 7.3 — что делать

Версия 7.3 сохраняет рабочий дизайн 7.2 и добавляет настоящую серверную часть:

- общая база учеников и уроков;
- личный кабинет ученика по защищённой ссылке;
- привязка ученика к Telegram;
- уведомления об уроках, переносах, отменах, домашнем и оплате;
- очередь «На проверку» для сообщений, которые нельзя отправлять без Иры;
- автоматическая проверка напоминаний каждые пять минут.

## Сначала

1. Загрузи содержимое `docs` в папку `docs` репозитория.
2. Загрузи папки `backend` и `.github` в корень репозитория.
3. GitHub Pages оставь: `main /docs`.

## Затем подключи Supabase

Открой [CLOUD_SETUP.md](CLOUD_SETUP.md). Там только один последовательный сценарий без выбора вариантов.

## Безопасность

Не присылай Bot Token в чат и не добавляй его в обычные файлы GitHub. Он должен быть только в GitHub Secrets / Supabase Secrets.
