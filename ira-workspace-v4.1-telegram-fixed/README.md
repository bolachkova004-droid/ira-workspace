# Ira Workspace v4.1

Telegram Mini App и веб-приложение для преподавателя английского.

## Что исправлено в 4.1

- относительные пути сборки для GitHub Pages;
- безопасная инициализация Telegram SDK на разных версиях клиента;
- экран загрузки и понятная ошибка вместо белого экрана;
- Error Boundary для ошибок React;
- безопасное сохранение в localStorage;
- резервный генератор ID для старых WebView;
- проверка production-сборки в GitHub Actions;
- служебный адрес `/health.json`;
- отдельная инструкция по Main Mini App и Menu Button.

## Локальный запуск

```bash
npm install
npm run dev
```

## Публикация

Файлы `package.json`, `src`, `public`, `.github`, `index.html` и остальные должны находиться непосредственно в корне репозитория, а не внутри дополнительной папки.

В GitHub открой **Settings → Pages** и выбери **Source: GitHub Actions**. После загрузки файлов workflow автоматически соберёт папку `dist` и опубликует её.

## Самый простой способ публикации без сборки

В проекте есть готовая папка `docs`. В **Settings → Pages** выбери:

- Source: `Deploy from a branch`
- Branch: `main`
- Folder: `/docs`

После сохранения GitHub опубликует уже подготовленную веб-версию. Этот режим добавлен как резервный, чтобы приложение можно было открыть даже без корректно настроенного workflow.
