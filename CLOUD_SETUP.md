# Подключение облака и Telegram — один раз

## 1. Создай Supabase

1. Открой Supabase и создай новый проект `ira-workspace`.
2. Сохрани пароль базы данных.
3. В настройках проекта найди **Project ID / Reference ID**.
4. В настройках аккаунта Supabase создай **Access Token**.

## 2. Добавь пять секретов в GitHub

Открой репозиторий:

**Settings → Secrets and variables → Actions → New repository secret**

Добавь по одному:

| Имя | Что вставить |
|---|---|
| `SUPABASE_ACCESS_TOKEN` | Access Token из Supabase |
| `SUPABASE_PROJECT_ID` | Reference ID проекта |
| `SUPABASE_DB_PASSWORD` | пароль базы при создании проекта |
| `TELEGRAM_BOT_TOKEN` | токен `@ira_workspace_bot` от BotFather |
| `OWNER_SETUP_CODE` | придуманный длинный код, например 20+ случайных символов |

`OWNER_SETUP_CODE` запиши себе. Он понадобится ещё один раз в приложении.

## 3. Запусти готовую установку

1. В GitHub открой **Actions**.
2. Выбери **Deploy Ira Workspace backend**.
3. Нажми **Run workflow**.
4. Дождись зелёной галочки.

Workflow сам:

- создаст таблицы;
- сохранит серверные секреты;
- опубликует три Edge Functions;
- подготовит Telegram webhook и планировщик.

## 4. Подключи приложение

Открой Ira Workspace **внутри Telegram**:

**Настройки → Облако и Telegram-бот**

Адрес функции:

```text
https://ТВОЙ_PROJECT_ID.supabase.co/functions/v1/workspace-api
```

В поле кода вставь `OWNER_SETUP_CODE` и нажми **Подключить облако**.

Приложение автоматически:

- подтвердит твой Telegram-аккаунт;
- загрузит текущих учеников и уроки в базу;
- настроит webhook бота;
- включит проверку напоминаний каждые пять минут.

После этого нажми **Тест сообщения**. Расмус должен прислать сообщение тебе в Telegram.

## 5. Подключи ученика

Открой карточку ученика → **Доступ ученика**.

В буфер скопируются две ссылки:

1. ссылка на подключение к боту;
2. ссылка на личный кабинет с расписанием, оплатой и домашним.

Отправь этот текст ученику. После нажатия Start его Telegram будет связан только с его карточкой.

## Что будет отправляться

- **Авто** — бот отправит сам;
- **На проверку** — сообщение появится у Расмуса, отправка только после твоего нажатия;
- **Выкл** — сообщение не создаётся.

По умолчанию оплата остаётся «На проверку».
