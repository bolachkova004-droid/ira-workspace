# Облако и напоминания — Rasmus 7.6.0

После загрузки полной версии:

1. GitHub → Actions → `Deploy Rasmus backend` → `Run workflow`.
2. Дождаться зелёной галочки.
3. Открыть Rasmus в Telegram → Настройки.
4. Нажать `Настроить бота`.
5. Нажать `Тест мне`.
6. В карточке подключённого ученика нажать `Тест напоминания ученику`.

Расписание отправки:

- ученику: за 24 часа и за 2 часа до урока;
- преподавателю: за 30 минут до урока;
- преподавателю: план дня в 08:00 по часовому поясу кабинета;
- домашнее: за сутки до срока;
- оплата и последний урок абонемента: по выбранному режиму Расмуса.

Ученик должен один раз открыть персональную ссылку и нажать Start.
