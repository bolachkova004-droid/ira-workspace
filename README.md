# Ira Workspace v5.0 — Paper Planner

Telegram Mini App и рабочая система для преподавателя английского. Начните с файла `START_HERE.md`.

## Что уже работает

- новый белый дизайн в стиле тетради и ежедневника;
- новый маскот Иви;
- календарь: месяц, неделя и день;
- создание, перенос и отмена уроков;
- персональные ссылки для учеников;
- student portal: уроки, оплаты, домашнее и материалы;
- запрос переноса от ученика;
- очередь Telegram-оповещений;
- ученики, уроки, заявки, контент, касания и аналитика;
- локальное сохранение и экспорт резервной копии;
- готовая статическая папка `docs` для GitHub Pages;
- облачная синхронизация через проверенный Telegram `initData`;
- student portal получает реальные данные из Supabase после подключения.

## Серверная часть в комплекте

В папке `supabase` находятся:

- production SQL-схема;
- RLS-политики;
- Edge Function для Telegram webhook;
- Edge Function для отправки уведомлений;
- Edge Function для безопасного student access;
- триггеры напоминаний и обновления просроченных оплат.

Подключение описано в:

- `SUPABASE_SETUP.md`
- `TELEGRAM_BOT_SETUP.md`

## Локальный запуск

```bash
npm install
npm run dev
```

## Публикация без сборки

В GitHub Pages выберите:

- Source: `Deploy from a branch`
- Branch: `main`
- Folder: `/docs`

## Важное ограничение

До подключения Supabase данные хранятся в браузере конкретного устройства, а уведомления формируются в очереди, но не отправляются автоматически. После добавления секретов и Edge Functions отправка работает через Telegram Bot API.
