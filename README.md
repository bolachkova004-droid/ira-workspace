# Ira Workspace v3.0

Рабочее пространство преподавателя: ученики, уроки, заявки, аналитика и новый раздел **«Касания»** для игр, соцсетей, Taplink, материалов и продуктов.

## Локальный запуск

```bash
npm install
npm run dev
```

## Публикация через GitHub Pages

1. Загрузите файлы в репозиторий `ira-workspace` и отправьте их в ветку `main`.
2. В GitHub откройте **Settings → Pages**.
3. В разделе **Build and deployment** выберите **GitHub Actions**.
4. После выполнения workflow приложение будет доступно по адресу:
   `https://bolachkova004-droid.github.io/ira-workspace/`

Проект уже подключает Telegram Web App SDK и разворачивается на весь экран внутри Mini App.
