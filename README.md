# Rasmus 7.6.0

Обновление добавляет:

- автоматическую проверку облака при открытии приложения и раз в минуту;
- напоминания ученикам за 24 часа и за 2 часа до урока;
- напоминание преподавателю за 30 минут до урока;
- утренний план преподавателю в 08:00 с уроками, задолженностями и заканчивающимися абонементами;
- кнопку тестового напоминания в карточке ученика;
- отдельные настройки уведомлений ученикам и преподавателю.

## Установка

1. Загрузить содержимое архива в корень репозитория с заменой файлов.
2. Запустить GitHub Actions → `Deploy Rasmus backend` → `Run workflow`.
3. После зелёной галочки полностью закрыть Mini App и открыть снова.
4. В Настройках нажать `Настроить бота` один раз.

Секреты GitHub повторно создавать не нужно.
