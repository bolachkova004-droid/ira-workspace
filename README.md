# Ira Workspace 7.0 — clean rebuild

Полностью автономная статическая версия без React, npm, CDN и сборщика.

## Публикация на GitHub Pages

1. Загрузите папку `docs` в корень репозитория.
2. В Settings → Pages выберите `Deploy from a branch`, ветку `main`, папку `/docs`.
3. Проверка: `/health.json` должна вернуть версию `7.0.0`.

## Что работает

- главная панель;
- ученики и карточка ученика;
- создание, редактирование и удаление учеников;
- календарь, добавление, перенос и отмена уроков;
- центр напоминаний;
- контент-доска;
- аналитика;
- локальное сохранение данных;
- демо-кабинет ученика по параметру `?student=<id>`;
- безопасный запуск в обычном браузере и Telegram WebView.

## Ограничение

Реальные Telegram-уведомления и синхронизация между устройствами требуют закрытого сервера и Bot Token. Они намеренно не включены в публичную статическую сборку.
