# Rasmus Beta 8.0.0

Закрытая beta-версия Telegram Mini App для преподавателей.

## Главное в 8.0

- отдельный workspace для каждого преподавателя по проверенному Telegram `initData`;
- существующий кабинет владельца сохраняется;
- новые участники начинают с пустого кабинета и короткого onboarding;
- автоматический публичный адрес Supabase Edge Function — участникам не нужны URL, токены и OWNER_SETUP_CODE;
- фокус-группа входит по `https://t.me/ira_workspace_bot?start=beta`;
- встроенная отправка отзывов и ошибок владельцу Rasmus;
- перенос и отмена урока;
- отчёт после урока остаётся условием списания занятия;
- touch-first кнопки, sticky actions и защита от iOS zoom при вводе;
- синхронизация телефона и компьютера в рамках Telegram-аккаунта.

## Развёртывание

1. Загрузить содержимое архива в корень GitHub-репозитория с заменой файлов.
2. Дождаться зелёного `pages-build-deployment`.
3. Запустить `Actions → Deploy Rasmus backend → Run workflow`.
4. Проверить `docs/health.json` — версия должна быть `8.0.0`.
5. Открыть Rasmus своим Telegram-аккаунтом и убедиться, что существующие данные владельца на месте.
6. В `Настройки → Фокус-группа` скопировать приглашение для тестеров.

Новая миграция базы для 8.0 не требуется: multi-user режим использует уже существующие `teachers` и `workspace_states`, а все Edge Function запросы привязываются к проверенному Telegram ID.
