# Ira Workspace v6.0 — Расмус

Рабочий Telegram Mini App для преподавателя английского на основе утверждённого тёмного CRM-концепта.

## Что входит

- Главная панель с Расмусом, уроками, оплатами и заявками.
- Карточка ученика: прогресс, пакет, домашние задания, заметки, материалы и Telegram.
- Календарь месяца с созданием, переносом и отменой уроков.
- Автоматическое обнаружение пересечений уроков.
- Персональная ссылка и Telegram-ссылка для каждого ученика.
- Личный кабинет ученика: уроки, оплата, домашнее, материалы и запрос переноса.
- Центр уведомлений с режимами `Авто`, `На проверку`, `Выкл`.
- Безопасная очередь: сообщения «На проверку» не отправляются Cron до одобрения.
- Контент, касания, заявки, аналитика, настройки и резервные копии.
- Supabase Edge Functions для Telegram webhook, student access и отправки уведомлений.
- Готовая папка `docs` для публикации через GitHub Pages без локальной сборки.

## Быстрая публикация

1. Загрузите всё содержимое проекта в корень репозитория `ira-workspace`.
2. GitHub → **Settings → Pages**.
3. Выберите **Deploy from a branch**, ветка `main`, папка `/docs`.
4. Откройте `https://bolachkova004-droid.github.io/ira-workspace/health.json`.
5. Ожидаемый ответ: `version: 6.0.0`, `status: ok`.

## Что требует личных секретов

Интерфейс и локальные данные работают сразу. Для облачной синхронизации и настоящих сообщений студентам нужно один раз подключить Supabase и добавить Bot Token только в Supabase Secrets. Не размещайте токен бота в GitHub.

Подробности:

- `START_HERE.md`
- `SUPABASE_SETUP.md`
- `TELEGRAM_BOT_SETUP.md`
- `QA_REPORT.md`
