# Ira Workspace v3.1

Рабочая версия Telegram Mini App для преподавателя английского.

## Что добавлено

- раздел «Контент» с Kanban-доской;
- карточки для Threads, Telegram и Instagram;
- этапы: идея, черновик, готово, опубликовано;
- дедлайны, теги и заметки;
- сохранение данных в браузере;
- HashRouter для стабильной работы на GitHub Pages;
- актуальная дата на главном экране.

## Запуск

```bash
npm install
npm run dev
```

## Публикация

После загрузки файлов в ветку `main` GitHub Action автоматически соберёт и опубликует приложение.
