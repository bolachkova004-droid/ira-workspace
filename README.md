# Ira Workspace 7.4 — Абонементы и надёжное сохранение

Исправлено:
- новые ученики сразу сохраняются локально и в облаке;
- незавершённая синхронизация не затирается при следующем запуске;
- добавлена карточка абонемента в профиль ученика;
- считаются всего, использовано, осталось, стоимость, оплачено и долг;
- при статусе урока «Проведён» занятие автоматически списывается;
- при возврате статуса списание отменяется;
- напоминания не отправляются для уже проведённых уроков.

Публикация сайта: заменить файлы в `docs`.
Backend: после загрузки обновлённой папки `backend` повторно запустить workflow Deploy Ira Workspace backend.
